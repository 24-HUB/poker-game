# Looking Glass Club — interactive lobby prototype

Run from the repository root:

```powershell
node prototype/server.cjs
```

Open http://127.0.0.1:4173. No dependencies or build step are required.

This is a local design prototype, separate from the planned Next.js/NestJS application. Create Room opens a sample waiting room. Join Room accepts the sample code `TEA123`, a room created in the current page session, or a valid preview URL. Sharing a link previews the join UI; it does not establish shared room state. Refresh resets locally created room state. No authentication, live poker, purchases, real balances, ticket spending, or gacha outcomes are implemented.

Collection and Invitations are descriptive preview screens. The working title, Alice name, sample balance, and character asset are provisional.
